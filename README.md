# «Арома Дом» — подсистема учёта материалов

Сайт на **ASP.NET MVC 5 (.NET Framework 4.8)** для варианта
**В6_КОД 09.02.07-2-2025-ПУ**: материалы, рецептуры и расчёт требуемого
количества по Приложению 1; оформление — по Приложению 2.

**Стек:** C# · ASP.NET MVC 5 · Razor · SQL Server (LocalDB) · Bootstrap 5 + своя тема.

---

## Быстрый старт

### 1. База данных

Откройте `db/AromaDom.sql` в SQL Server Management Studio (подключение
`(localdb)\MSSQLLocalDB`) и выполните скрипт. Либо из консоли:

```bat
sqlcmd -S "(localdb)\MSSQLLocalDB" -E -i db\AromaDom.sql
```

Скрипт создаёт базу `AromaDom`, 7 таблиц, представления, триггеры и заливает
данные заказчика: 10 типов материалов, 4 единицы измерения, 18 материалов,
6 типов продукции, 14 продуктов, 73 рецептуры.

Строка подключения — в `WebApplication8/Web.config`:

```
Data Source=(LocalDB)\MSSQLLocalDB;Initial Catalog=AromaDom;Integrated Security=True
```

### 2. Запуск сайта

Откройте `WebApplication8.slnx` в Visual Studio 2026 и нажмите **F5**.

Без Visual Studio:

```bat
"C:\Program Files\IIS Express\iisexpress.exe" /path:"%CD%\WebApplication8" /port:8099
```

и откройте `http://localhost:8099/`.

## Страницы

| Адрес | Назначение |
|---|---|
| `/` | главная: материалы по категориям — чипы категорий и секции с карточками |
| `/Materials` | каталог: все позиции, поиск и фильтр по категории |
| `/Materials/Create` | добавление материала (7 полей) |
| `/Materials/Edit/{id}` | редактирование, поля заполнены из базы |
| `/Materials/Products/{id}` | продукция, где используется материал, и норма расхода |

Карточка показывает тип, наименование, минимальное количество, остаток,
цену с единицей измерения и требуемое количество — как в макете задания.
Клик по карточке открывает редактирование, ссылка «Продукция» — список продукции.

## База данных

7 таблиц в третьей нормальной форме:

| Таблица | Назначение |
|---|---|
| `material_type` | типы материалов, процент потери сырья |
| `unit` | единицы измерения |
| `material` | карточка материала: цена, упаковка, остаток, минимум |
| `product_type` | типы продукции, коэффициент типа |
| `product` | продукция: артикул, тип, минимальная стоимость |
| `material_product` | рецептура: норма расхода на единицу продукции |
| `material_stock_history` | история изменения остатка (заполняется триггером) |

Ссылочная целостность — внешние ключи; ограничения `CHECK` на цену ≥ 0,
остаток и минимум ≥ 0, упаковку > 0, норму расхода > 0, потери в [0; 100).
Представления `v_material_card` (карточка + требуемое количество) и
`v_material_product` (продукция по материалу). Триггеры обновляют отметку
времени и пишут историю остатков.

## Модуль 4

`Services/ProductCalculator.cs` — метод `Calculate(productTypeId,
materialTypeId, rawAmount, param1, param2, lookup)` возвращает целое
количество продукции или −1:

```
расход на изделие = параметр 1 × параметр 2 × коэффициент типа продукции
полезное сырьё    = количество сырья × (1 − процент потери / 100)
количество        = floor(полезное сырьё / расход на изделие)
```

Справочники читаются через `IProductLookup`, который реализует
`MaterialRepository`; это позволяет тестировать метод без базы.

## Примечания

* Проект создан Visual Studio как **MVC 5 на .NET Framework 4.8** —
  это не ASP.NET Core; EF Core здесь не применяется, доступ к данным через
  `System.Data.SqlClient` (ADO.NET).
* Имя проекта — `WebApplication8`. Для модуля 4 нужен отдельный репозиторий
  с именем проекта; если переименуем проект в `AromaDom`, репозиторий
  получит то же имя.
* Папка `docs/` и `db/` лежат рядом с решением и в сборку сайта не входят.
